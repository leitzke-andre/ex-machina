Editor: Default

A preset is a complete configuration. Use loads it into the editor and, with the device connected, sends it (it is not kept on the device until you press Save on device).

Backup and sharing

Your presets are kept in this browser (for this address). A file made here can be imported on another computer; tools/midi_patch/mmk3_config.py preset apply NAME FILE sends one from the command line.

Transport buttons Play, Rec and Stop only; everything else stays as it is.

A button can have a second action for when a button set to Shift (hold) is held down. The device's own functions (pad modes, Fixed Vel, velocity curve, transpose, panic) change how the pads play and show a message on the screen for a moment; the preset Maschine-like modes sets them up the way NI's buttons are named.

First pad note

Note names use middle C = C3 (note 60), so note 36 is C1. The pads are drawn as they sit on the device: pad 1 is the bottom left.

The velocity curve is NI's own set. A button set to Velocity curve: step changes it on the device (and the device remembers the choice without saving; saving the mapping keeps it as well). Fixed Vel, Keyboard and Chords mode (with the scale and chord type it starts with; buttons can step through them) work with buttons set to those functions. The arp (a button set to Arp / Note Repeat) plays the notes of the held pads in time, at the tempo below (tap it with Tap tempo; an incoming MIDI clock takes over); with the repeat pattern it is NI's Note Repeat. Several apps mishandle polyphonic aftertouch: channel pressure or a CC (for example 11) or off may suit them better.

Encoder targets

Buttons set to Encoder target point the encoder at one of these CCs instead (absolute values, shown on the screen); pressing the same button again goes back to the CC above.

Velocity gain scales how hard you have to hit for a given velocity (and the pressure messages). The sensitivity sets the threshold at which a touch counts as a hit; "device default" keeps the value the device has stored.

Local lighting

The device lights itself, without any app sending LED messages.

LED messages from apps arrive on channel

An app can light single LEDs with Note On messages on that channel (note = LED number), or a pad with its own note on the main channel; velocity = colour × 4 + brightness.

On the device

"Save on device" keeps the mapping across power cycles. Erasing the saved settings also puts the defaults back.

Preset slots on the device

Four configurations kept in the device's own flash, to switch without a computer (buttons set to Preset slot; the Maschine-like preset uses Scene / Pattern / Events / Variation, Shift stores). Store current keeps what is active now; Make active loads a slot (not saved as the power-up configuration: Save on device does that).
