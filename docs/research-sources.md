## Groove Rider 2 (iOS app by JimAudio): research for a preset (2026-10-18)
Done by a research agent from public sources (App Store text, the manual PDF as a text conversion, a 68-page Loopy Pro forum thread); nothing here was tried in the app or on the device. Links: [App Store](https://apps.apple.com/app/groove-rider-2/id6480135731), [manual](https://www.jimaudio.pro/grooverider2/GrooveRider2_Manual.pdf), [forum thread](https://forum.loopypro.com/discussion/63978/jim-audio-groove-rider-2-released/p1), [MIDI control thread](https://forum.loopypro.com/discussion/66498/groove-rider-2-midi-control).

**First test on an iPad (2026-10-18, the user, Groove Rider 2 with the draft preset)**: pads work in Trigger and Keys mode (the app's pad lights while the Mikro pad is held); the strip sweeps the filter (CC 74); Solo / Mute throw the selected Part into send A / B (125 %, the maximum, while held, back to 0 on release); the local lighting behaves. **The encoder did not work**: Last Knob Control learned **CC 9** (the encoder's *touch* sensor, which sends 127 when the finger lands, before the first turn message) and then ignored the turn. Fix in the preset: the encoder touch sends nothing, so the app learns the rotation (CC 20); **retested: the encoder works** (relative, two's complement). The push stays CC 8 at the user's request (it sends only when pressed, so it does not disturb the learn). All five controls tested on the iPad now work; the preset lost its "draft" label.

**What follows for the Mikro**: as a generic controller it gets the pads (notes 36-51), the strip (CC 74 = cutoff), an endless encoder for Last Knob Control (relative CC), and send throws (Solo / Mute = CC 91 / 92, which are also NI's defaults for those buttons), but not the transport or the clip grid. The built-in preset *Groove Rider 2* sets exactly those. Options that need more work: (1) a **USB HID keyboard** interface sending the documented shortcuts (Space, Cmd-R, arrows) would reach the transport and Part navigation, at the price of a composite-descriptor change on a working device and the on-screen keyboard hiding when a keyboard is attached; (2) **Launchpad emulation** (name, SysEx, programmer-mode notes, a palette lookup for the LEDs) is not recommended: 16 pads against an 8x8 grid, unknown handshake, and it would impersonate another maker's product; (3) ask the developer for MIDI Start / Stop and learnable transport.

## Four more iOS apps (2026-10-18, research agents on public sources; nothing tried yet)
Each became a built-in *draft* preset (`builtin_presets()` in `tools/midi_patch/mmk3_config.py`). Common finding: none of them sends LED feedback to a generic controller, none has a controller mode usable by a Mikro, and in the three apps without MIDI-learnable transport the only routes are MMC, CC numbers you enter, or a hardware keyboard. The encoder touch must send nothing in every app preset (learn grabs the first message).
- **Korg Gadget 3** ([Studio Guide](https://www.korg.com/us/support/download/manual/0/170/2363/), 2025-05-30): Native Mode only for Korg's controllers; generic MIDI input (Easy: the track with the lit MIDI button; Advanced: per track device and channel); CC learn for gadget parameters only; a *Transport CC* feature (play, pause, stop, record, loop, metronome) with no documented numbers; no MMC, no note map for the drum gadgets; default CCs per gadget from a community chart (CC 3, 6, 96-99, 119 unused by every gadget as of 2022). Preset: Play/Stop/Rec/Restart/Tap = CC 3/119/2/118/117 on press, encoder CC 7, strip CC 1.
- **Cubasis 3** ([help](https://download.steinberg.net/downloads_software/Cubasis/Cubasis_3_Web_Help/SETUP.html), up to 3.7; app is 3.8.6): MIDI Learn (CC and note only, 64-127 toggles a button, no SysEx so **no MMC**), Mackie/HUI (blocks learn, wants feedback); clock out but not in; drum tracks GM-like (36-51) but Classic Machines kits are not in order (forum). Learning Record by CC was reported flaky in 2021. Preset: CC 102-114 for transport/navigation/mute/solo, encoder CC 20, strip CC 21.
- **FL Studio Mobile** ([manual](https://www.image-line.com/fl-studio-learning/fl-studio-mobile-online-manual/html/plugins/), App Store 4.10): no controller integrations, no MIDI out, no clock; **drum pads start at note 48**; learn is CC-only ("Link to MIDI CC"); transport only by **MMC** (play, pause, stop, rewind, arm record). Preset: pads 48-63, MMC transport, CC 20-31 toggles, encoder CC 102.
- **GarageBand for iPad** ([guide](https://support.apple.com/guide/garageband-ipad/)): no MIDI learn or mapping; Bluetooth/USB MIDI devices play touch instruments; MPE setting; clock out only; transport by keyboard shortcuts (Space, R, `,` `.`); CC 1/7/8/64 from an unsourced 2013 forum list; a forum claim that transport answers MMC. Preset: pads 36-51, strip CC 1, encoder CC 7, Note Repeat = CC 64, MMC transport.
